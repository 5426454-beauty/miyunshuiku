一、当前 UI 问题诊断
─────────────────────

| 问题 | 现象 | 路演影响 |
|------|------|---------|
| 按钮泛滥 | 场景左下角堆积 8+ 个悬浮按钮（POI/天气/可视域/闸门/降雨/无人机/地图分析/淹没分析） | 观众看不懂、演示者找不到 |
| AI 聊天太小 | 底部角落 300×400 窗口，不显眼 | 整场演示靠 AI 驱动，但 AI 藏在角落 |
| 双 AI 对话冲突 | 地图分析面板有独立 AI 对话，底部还有 AI 助手 | 混乱，听众不知道看哪 |
| 左右面板占空间 | 280px × 2 = 560px 固定面板，全是不变的数据 | 挤占 3D 场景，演示中用不上 |
| 淹没控制栏居中 | 底部 360px 宽控制栏横跨屏幕 | 挡住其他元素，不够简洁 |
| 2D/3D 切换分散 | 顶部小按钮，切换后 UI 变化大 | 观众跟丢场景 |
| 无演示状态管理 | 所有功能随时可用，没有"演示模式" | 演示者容易点错、进错状态 |

四、新增组件详细设计
─────────────────────

4.1 快速操作条（Quick Action Bar）
─────────────────────────────────
位置：场景底部左侧，AI 窗口上方
外观：3-5 个小按钮横向排列，半透明背景
功能：根据当前幕自动切换可用按钮

  第1幕 —— 隐藏
  第2幕 —— [🌧暴雨] [📊 DEM分析] [🌊淹没热力]
  第3幕 —— 隐藏（由AI对话驱动分析流程）
  第4幕 —— [✅确认执行] [❌取消]
  第5幕 —— [🌊淹没热力] [⏯播放] [🔝峰值] [🚪闸门]
  第6幕 —— [📊对比分析]
  第7幕 —— 隐藏


4.2 AI 对话窗口（增强版）
─────────────────────────
位置：场景底部居中，可拖拽调整位置
大小：3 种预设尺寸切换
  - 最小化：380×120，只显示最后一条（第5/6幕）
  - 标准：600×400，显示近 5 条对话（第1幕开始）
  - 全高：800×550，显示完整对话历史（第2/3/4幕主交互）
输入：文字 + 语音（Web Speech）
特殊：每条 AI 回复渲染为卡片式，包含分析数据摘要


4.3 步骤指示器（Step Indicator）
─────────────────────────────────
位置：场景顶部居中，top-bar 下方
外观：横向步骤条，4-5个步骤圆点 + 标题
显示时机：第4幕和第5幕

  第4幕：
  ○──●──○──○──○
  预警  评估  决策  执行  验证
        ▲ 当前

  第5幕（4阶段淹没演进）：
  ○────●─────○──────○
  T+6h  T+12h  T+18h  T+24h
          ▲ 当前


4.4 DEM 标注浮层信息卡
─────────────────────────
当 DEM 分析或图像检测完成后，在 3D 场景右上角浮出一个小卡片：

  ┌───────────────────┐
  │ 📊 风险画像         │
  │ 🌊 低洼区 2处      │
  │ 🏠 建筑 23栋(15栋⚠)  │
  │ 🛣 道路 3.2km      │
  │ 💧 最大水深 1.8m    │
  └───────────────────┘

5 秒后自动缩小为图标，点击可重新展开。

五、侧面板收折方案
───────────────────

路演时侧面板不需要展示——那是给日常值班看的。实现方案：

  .side-panel--left   { width: 20px; overflow: hidden; transition: 0.3s; }
  .side-panel--left:hover  { width: 280px; }
  .side-panel--right  { width: 20px; overflow: hidden; transition: 0.3s; }
  .side-panel--right:hover { width: 280px; }

收折后显示一个竖条，鼠标悬停展开。API 关键字触发也可展开（如 AI 说"显示左侧面板"）。


六、2D/3D 切换改进
───────────────────

当前：顶部 3 个小按钮 [3D] [🛰卫星] [🗺标准]
问题：太小，观众看不到

改进：切换按钮移到右侧面板上方，加大尺寸
  - [🏔 3D 场景]  [🛰 卫星影像]  [🗺 标准地图]
  - 当前激活态高亮、动画过渡
  - 在第 3 幕 AI 分析时自动切换到卫星图（截图给 Vision 模型）


七、待开发清单（按优先级）
